# 网络、共享与终端恢复：未发行源码改动

本说明记录当前源码实现，不代表已替换用户正在运行的 Cage、已生成发行安装包，或已完成所有原生平台实机验收。设计与验收记录见[根治重构文档](../network-recovery-refactor.md)。

## 实现

- SFTP 收包、排序与发送分离，发送错误取消会话；Close 可中断阻塞写，不再等待发送锁；完整处理短写。有界准入与受限服务发送截止时间限制卡死会话。
- Unix 宿主的默认 Lima builtin reverse-sshfs 中转使用单个双工 socketpair；Linux 工作台项目共享使用固定身份的原生 Go SSH channel，不经过外部 SSH 的双向 OS pipe。
- 每个项目独立恢复，保存目录对象身份、授权代次与挂载状态。只清理 Cage 自己的挂载；下层目录保持 root-owned mode 000。撤销授权或替换目录不能被晚到重连反转。
- 容器运行意图持久化，Recover 只恢复已运行、期望仍为 running 的容器网络 worker，不启动被停止的容器。默认共享、浏览器和 VNC 故障不再导致整条网络退出。新的网络代次不能沿用旧外网租约；人工暂停继续生效。
- Linux 客机 PTY 与 shell 独立存活，宿主 SSH 和 UI 可以按会话身份重新附着。创建结果不确定时先查询，同一客机服务代次内去重；代次变化后不自动重新执行命令。明确 Stop 结束进程，控制服务退出只 detach。
- 终端输出有界保留，缺口明确提示；回放逐帧标记，避免重复剪贴板和 CLI 对话操作。输入区分 accepted、written、unknown，不自动重发。登录输出不保留历史或落盘。
- 外层 SSH 有心跳、有限退避和固定主机/实例核验；重连只连接既有服务。新连接代次拒绝旧 API、文件选择和输入结果，不自动部署、启动环境或重新提交修改操作。
- 帧传输复用缓冲、合并帧头与数据写入，移除不必要的 net.Pipe 中转，保留最大帧、来源 MAC、截止时间及关闭语义。

## 保留的限制

不会透明恢复旧 sshfs 文件句柄、mmap、cwd、已经退出的进程、客机重启前的内存或已经断开的公网 TCP。旧终端不能运行中迁移 PTY 所有权。macOS、Windows 原生终端保持既有实现，没有宣称新增进程恢复。未对这两个平台、无人登录常驻或服务器重启进行实机验收。源码实现不以直接 bind mount、跳过 SSH 身份核验或自动放行外网作为回退。

创建去重记录采用当前服务代次内的有界安全记账，记满时拒绝新建，不为继续创建而自动重启仍运行的 shell。结束会话输出有 32 个／合计 2MiB 的保留上限，较早画面可能无法附着；这些预算与恢复边界列在实施文档中。
